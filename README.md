### 🛠️ Featured Projects

#### 🎯 [HUNTERS — Multi-Agentic AI Job Application System](#) `In Progress`
> Terminal-based, voice-first multi-agent system automating the entire job application pipeline.
- Built an async, full-duplex voice pipeline over WebSockets (Silero VAD + Sarvam STT + Edge TTS) for near-zero latency, feedback-free conversation
- Designed a LangGraph ReAct orchestration layer separating a low-temperature tool-calling Planner from an expressive voice-generation node
- Engineered a Dual-Memory Architecture — SQLite for short-term checkpointing + ChromaDB (BGE embeddings) for long-term semantic recall — to work around a 6K TPM context limit
- Deployed a centralized MCP tool server via FastMCP for secure agent access to web search, filesystem, and memory

**Stack:** `Python (Asyncio)` `LangGraph` `Llama 3 (Groq)` `ChromaDB` `MCP` `WebSockets`
